📚 Quick Guide

What is a Hash?

A unique fingerprint of your message. Any change to the message changes the hash completely.

What is a Signature?

Digital proof that the message came from Alice and hasn't been tampered with.

What is Lamport OTS?

A quantum-resistant signature scheme where each key pair can only be used once for security.
